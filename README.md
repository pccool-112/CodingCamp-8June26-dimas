# Expense & Budget Visualizer

Build a mobile-friendly Expense & Budget Visualizer using:
- HTML
- CSS
- Vanilla JavaScript
- Local Storage API
- No backend
- No frontend framework

Important HTML rule:
- Do not use <div>.
- Use semantic HTML elements such as header, main, section, article, aside, footer, form, ul, li.

Required features:
- Input item name, amount, and category.
- Add transaction.
- Validate form input.
- Show transaction list.
- Delete transaction.
- Show total balance.
- Show pie chart by category.
- Store data in Local Storage.

Optional challenges selected:
- Custom categories.
- Sort transactions by amount or category.
- Dark/light mode toggle.
